03 боли старого пути

Что не работало

Это не про «дизайнер плохой» — это про процесс, где каждый шаг последовательный, без возможности параллелить.

⏰

Дизайнер — блокер

было

1 дизайнер делает 1-2 лендинга в месяц. Хочешь больше — нанимай ещё. Хочешь быстрее — никак.

🔁

Копирайт переписываем

было

Сначала пишешь под ТЗ. Потом дизайн поменялся — переписываешь под макет. Потом верстка — снова поправки.

07 главное отличие

Было vs стало — в цифрах

Не «дизайнер стал быстрее», а процесс другой. Больше нет последовательных шагов с блокерами — Claude собирает черновик из интервью, остальное параллельно.

📉 Раньше

10–14 дней
  • 1 дизайнер = 1-2 лендинга / месяц
  • Копирайт переписываем 2–3 раза
  • ТЗ → дизайн → верстка — каждый шаг блокер
  • Гипотезы дороже — реже тестируем
  • Figma → Tilda — двойная работа
  • Нужны: дизайнер + копирайтер + верстальщик

📈 Сейчас

1-2 дня (тест: часы)
  • Дизайнер для финиша, не для черновика
  • Копирайт + дизайн рождаются вместе в Claude
  • Параллелим: гипотеза → HTML за час → правки
  • Тестируем 5+ гипотез в неделю
  • Auto-export в Figma — без двойной работы
  • Нужны: 1 человек с Claude + по желанию диз
08 итог

×10 скорость.
